# 관리자 사용설명서

이 문서는 관리자 페이지의 모든 기능을 처음 쓰는 사람도 따라 할 수 있도록 설명합니다.
앱 안에서는 **관리자 대시보드 → 📖 사용설명서**(`/admin/help`)에서 같은 내용을 볼 수 있습니다.

---

## 시작하기

- 관리자 페이지는 상단 탭으로 이동합니다: **대시보드 · 전체 유저 · 아웃리치 · 잘못된 URL · 사용설명서**.
- 현재 보고 있는 페이지는 상단 탭에서 진하게 표시됩니다.
- 관리자 계정으로 로그인해야 페이지가 열립니다. 권한이 없으면 "접근 권한이 없습니다"가 표시됩니다.
- 각 페이지의 **새로고침** 버튼으로 최신 데이터를 다시 불러옵니다.

---

## 대시보드 (`/admin`)

운영 지표, 문의, 사전등록을 한 곳에서 관리하는 시작 화면입니다.

### 운영 현황
- **무엇을 하나요?** 오늘/이번 주 활성 사용자, 가입 수, AI 생성 수, 구독, 무료체험 소진 현황을 한눈에 봅니다.
- **주의:** 숫자는 조회 시점 기준입니다. 최신 값은 **새로고침**을 누르세요.

### 문의 관리
- **무엇을 하나요?** 사용자가 앱에서 보낸 문의를 확인하고 답변합니다.
- **사용 방법:**
  1. 문의 목록에서 답변할 문의를 찾습니다. (기본은 미답변만 보기)
  2. 답변 입력란에 내용을 적고 **답변**을 누릅니다.
  3. 답변하면 사용자 화면의 문의 위젯에서 확인할 수 있고, 안 읽은 표시가 다시 뜹니다.
- **용어:** *미답변* = 아직 답을 보내지 않은 문의.

### 사전등록 (일괄 등록 / 개별 등록 / 등록 현황)
- **무엇을 하나요?** 회원가입 전에 사용자에게 미리 서비스 권한을 부여합니다. 이렇게 등록된 사람은 가입 전까지 "미가입" 상태로 보입니다.
- **일괄 등록:** 스프레드시트(엑셀/구글시트)에서 행을 복사해 붙여넣고 **미리보기 → 확정**합니다. 헤더(첫 줄)에 이메일 열이 반드시 있어야 합니다.
- **개별 등록:** 한 명씩 폼으로 추가합니다.
- **등록 현황:** 등록된 목록을 검색·정렬하고, 각 항목을 수정/삭제할 수 있습니다.
- **주의:** 이메일은 소문자로 관리됩니다. 같은 이메일을 다시 등록하면 기존 정보가 갱신됩니다.

### 사용자 조사
- **무엇을 하나요?** 특정 사용자를 이메일/이름으로 빠르게 찾아 프로필·구독·AI 생성 이력을 봅니다.
- **사용 방법:** 검색창에 이메일 또는 이름을 2글자 이상 입력 → 결과를 클릭하면 상세가 열립니다.

## 전체 유저 (`/admin/users`)

가입·미가입 사용자를 검색하고, 상세 정보를 확인하고, 크레딧을 지급하는 페이지입니다.

### 목록 보기 · 검색 · 필터
- 검색창에 이름·이메일·회사·브랜드·기관을 입력해 좁힐 수 있습니다.
- 필터: 가입 여부(가입/미가입), 이용 유형(무료/마케터/생성기), 주관기관, 가입일, 활동, 구독, 크레딧, 마케터 제출, 문의 등.
- 열 제목을 클릭하면 정렬됩니다.
- **엑셀 내보내기:** 현재 필터가 적용된 결과만 파일로 저장됩니다.

### 상세 보기 (행 클릭)
- 기본 정보, 최초 접속일/접속 횟수, 구독·잔여 크레딧, AI 생성물, 생성 로그, 마케터 제출 내역, 크레딧 지급 이력을 탭으로 봅니다.
- **마케터 제출 정보**는 이 화면에서 직접 수정할 수 있습니다.

### 크레딧 지급
- **무엇을 하나요?** 특정 사용자에게 보너스 생성 횟수를 즉시 지급합니다.
- **사용 방법:** 상세 → **크레딧 지급** 탭 → 수량·사유(관리자용)·사용자에게 보여줄 메시지 입력 → **지급하기**.
- **주의:**
  - 지급은 **즉시 잔여 크레딧에 더해지며 되돌릴 수 없습니다.** 수량을 꼭 확인하세요.
  - 활성 구독이 없으면 1개월 구독이 새로 만들어지며 지급 수량이 채워집니다.
  - 사용자는 다음 접속 때 "🎉 N회가 추가 지급되었습니다" 팝업을 한 번 보게 됩니다.

### 용어
- **미가입:** 아직 회원가입하지 않은 사전등록 사용자. 이메일/전화만 있고 로그인 기록이 없습니다.
- **주관기관:** 사용자를 사전등록해 준 기관(host_org).
- **무료 유저 / 마케터 구독 / 생성기 구독:** 결제·권한 상태를 구분한 열.

## 아웃리치 (`/admin/outreach`)

아직 가입하지 않은(미가입)·사전등록 사용자에게 안내/광고 메시지를 보내는 페이지입니다.

### 채널 상태
- 상단에 **이메일 / SMS / 알림톡**의 "설정됨 / 미설정"이 표시됩니다.
- 미설정 채널은 발송할 수 없습니다. (설정 방법은 담당 개발자에게 문의 — 환경변수 필요)

### 수신자 선택
- 검색과 필터(미가입/가입, 주관기관, 구독 상태, 마케터 대상)로 대상을 좁힙니다.
- **필터 전체 선택**으로 현재 필터의 모든 대상을 한 번에 선택하거나, 개별 체크할 수 있습니다.
- **수신거부**한 사람은 회색으로 표시되고 선택·발송에서 자동 제외됩니다.
- 이메일 채널은 이메일이 없는 대상이, SMS/알림톡은 전화번호가 없는 대상이 숨겨집니다.

### 메시지 작성
- 채널과 **구분(안내성 / 광고성)**을 고르고, 제목(이메일)·본문을 자유롭게 작성합니다.
- **개인화 변수:** `{{name}}`, `{{company}}` 를 쓰면 사람마다 이름/회사로 바뀝니다. 값이 없으면 빈칸으로 나옵니다.
- 선택한 첫 번째 대상 기준으로 **미리보기**가 실시간으로 보입니다.

### 테스트 발송 → 발송
1. **테스트 발송:** 내 이메일/전화번호로 먼저 보내 실제 모습을 확인합니다. (기록에 남지 않음)
2. **발송:** 대상 수 · 채널 · 예상 비용을 보여주는 **확인 창**이 뜹니다. 내용을 확인하고 **정말 발송하기**를 누릅니다.
3. 대량(200명 이상) 발송에는 경고가 표시됩니다.

### 발송 이력
- 캠페인별로 대상/성공/실패/건너뜀 수를 봅니다. 행을 클릭하면 수신자별 결과가 열립니다.
- **실패분 재발송:** 실패한 사람에게만 같은 내용을 다시 보냅니다.
- **이 내용으로 다시 작성:** 과거 캠페인의 제목·본문을 그대로 불러와 재사용합니다.

### 주의 (법적 표기)
- **광고성**으로 보내면 **(광고) 표기**와 **무료수신거부** 안내가 자동으로 붙습니다. 상품·서비스 홍보는 반드시 광고성으로 보내세요. (표시광고법 준수)
- 안내성은 단순 공지/안내에만 사용하세요.
- 알림톡은 원칙적으로 정보성 전용이라 미가입 대상 광고 발송에는 적합하지 않습니다. 미가입 홍보는 SMS(광고)를 권장합니다.

## 잘못된 URL (`/admin/marketer-urls`)

마케터 제출 내역 중 **형식이 잘못된 URL**만 모아 보여주는 점검 페이지입니다.

- **무엇을 하나요?** 인스타그램/유튜브 링크가 잘못 입력된 제출 건을 찾아 사용자에게 수정을 안내하기 위한 목록입니다.
- 각 행은 제출자, 어떤 필드의 URL인지, 입력된 값, 문제 사유를 보여줍니다.
- 문제 URL이 없으면 "형식 오류 URL이 없습니다 🎉"가 표시됩니다.

---

## 자주 하는 실수 · 주의

- **크레딧 지급은 되돌릴 수 없습니다.** 수량을 다시 확인하고 지급하세요.
- **광고 메시지는 반드시 "광고성"으로.** 안내성으로 홍보를 보내면 법 위반 소지가 있습니다.
- **대량 발송 전 테스트 발송**으로 실제 모습을 먼저 확인하세요.
- **엑셀 내보내기는 현재 필터 결과만** 저장합니다. 전체를 원하면 필터를 초기화하세요.
- 숫자가 이상하면 대부분 **새로고침**으로 해결됩니다(조회 시점 데이터).
